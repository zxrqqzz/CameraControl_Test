## 一、已完成：相机内参标定（张正友闭合解）

### 位置

`src/CameraControl.Domain/Calibration/`

| 文件 | 内容 |
|---|---|
| `CalibrationTypes.cs` | `Point2/Point3`、`ChessboardSpec`、`CalibrationView`、`CameraIntrinsics`、`ICameraCalibrator` |
| `SymmetricEigen.cs` | 6×6 / 9×9 对称矩阵特征分解（循环 Jacobi） |
| `ZhangCalibrator.cs` | 归一化 DLT 求单应 → Zhang 约束 → 提取内参 |

纯数学、零依赖，因此放在 **Domain** 层（和振动位移分析同层）。

### 算法链路

```
多张棋盘格图像
   ↓ 每个视角：归一化 DLT（Hartley 归一化 + 最小特征向量）
单应矩阵 H（物平面 → 像平面）
   ↓ 列向量构造 Zhang 约束
v12·b = 0,  (v11 − v22)·b = 0     → 2N×6 方程组
   ↓ 最小特征向量（Jacobi）
B = K⁻ᵀK⁻¹ 的 6 个元素
   ↓ 闭式公式
fx, fy, cx, cy
```

### 验证方式：合成数据反演

没有真实标定板时，唯一能证明算法正确的方式是**用已知内参投影，再反解回去**。

真值：`fx=1200, fy=1198, cx=641.5, cy=479.25`，图像 1280×960，棋盘 9×6 / 10mm，10 个姿态各异的视角。

| 测试 | 条件 | 判据 | 结果 |
|---|---|---|---|
| 无噪声还原 | 0 噪声 | fx/fy 相对误差 < 0.5% | ✅ 通过 |
| 亚像素噪声 | ±0.3px 均匀噪声 | fx/fy 相对误差 < 1%，主点 < 5px | ✅ 通过 |
| 视角不足 | 只有 2 个视角 | 返回 `CALIB_TOO_FEW_VIEWS` | ✅ 通过 |
| 退化配置 | 同一视角重复 5 次 | 返回失败而非错误结果 | ✅ 通过 |

## 二、已完成：机器人端口契约

### 位置

`src/CameraControl.Domain/Robotics/RobotPorts.cs`

```csharp
public interface IRobot
{
    string AdapterName { get; }
    Task<RobotState> GetStateAsync(CancellationToken ct);
    Task<RobotMotionResult> MoveToAsync(RobotPose target, TimeSpan timeout, CancellationToken ct);
    Task StopAsync(CancellationToken ct);   // 安全动作
}
```

### 设计决定

**① 端口只暴露"绝对位姿 + 停止 + 读状态"**，不暴露关节、IO、速度曲线。需要时再扩展，避免被某一家控制器绑死。

**② `robot.stop` 风险等级定为 Reversible 且免确认。**
危险时刻不该因为"要不要弹窗"耽误急停——**AI 也能直接调用**（有测试锁死）。

**③ 未接入时用 `UnavailableRobot` 占位，而不是抛异常。**
让上层（含 AI）能问到明确答案："state=Disconnected，未配置机器人"，
而不是得到一个含糊的失败。这是"诚实占位"的同一个原则。

### 新增能力（3 个）

| id | 风险 | 确认 | 说明 |
|---|---|---|---|
| `robot.getState` | ReadOnly | — | 读连接状态与位姿 |
| `robot.stop` | Reversible | **否** | 急停，AI 可直调 |
| `robot.moveTo` | **Physical** | **是** | 绝对位姿运动，必须人工确认 |

## 七、手眼标定 AX = XB（已实现并验证）

> 状态：**求解器已完成，合成数据验证通过**；尚未接真实机器人。

### 记号与方程

| 符号 | 含义 |
|---|---|
| `T_robot_i` | 末端法兰在机器人基坐标系的位姿（机器人给出） |
| `D_i` | 靶标 → 相机的变换（BA 输出的每个视角位姿） |
| `X` | **待求**：相机相对末端法兰的位姿 |

相对运动：

```
A_ij = T_robot_j⁻¹ · T_robot_i        末端法兰的相对运动
B_ij = D_j · D_i⁻¹                    相机的相对运动
```

则 `A·X = X·B`，解出 X 即完成手眼标定。

### 解法（Tsai/Lenz 四元数版）

1. **旋转**：`q_A ⊗ q_X = q_X ⊗ q_B` 关于 `q_X` 是**线性**的，
   用 `(L(q_A) − R(q_B))·q_X = 0` 堆叠取最小特征向量（复用项目内的 Jacobi 特征分解）。
2. **平移**：由 `A·X = X·B` 得 `(R_A − I)·t_X = R_X·t_B − t_A`，最小二乘。
3. **残差**：逐对计算 `A·X` 与 `X·B` 的偏差，报告最大旋转/平移残差。

用四元数而不是轴角：对噪声更稳，且不用处理 180° 奇点。

### 位置

| 文件 | 内容 |
|---|---|
| `Domain/Calibration/Transform3D.cs` | 刚体变换、欧拉角（ZYX/XYZ）、四元数互转 |
| `Domain/Calibration/HandEyeCalibrator.cs` | AX=XB 求解与残差评估 |
| `BundleAdjustmentCalibrator.SolveDetailed` | 输���每个视角的位姿，供手眼使用 |

### 验证（合成数据）

真值 X：平移 (20, −15, 80) mm，旋转 (5, −8, 12)°；10 个姿态各异的机器人位姿；靶标固定在基座系。

| 测试 | 判据 | 结果 |
|---|---|---|
| 还原 X | 旋转 <0.1°，平移 <0.1mm | ✅ |
| 残差 | <0.05° / <0.05mm | ✅ |
| 采样不足 | 明确报错 | ✅ |
| 机器人不动 | 因"缺乏旋转信息"拒绝 | ✅ |
| 欧拉角↔四元数互逆 | <1e-6° | ✅ |
| 逆变换还原单位变换 | <1e-6 | ✅ |

### 重要前提（现场必须注意）

1. **机器人姿态必须有明显旋转差异**——纯平移运动无法解出手眼（代码里已按 3° 阈值过滤并明确报错）。
2. **欧拉角约定必须核对**。默认 `R = Rz·Ry·Rx`（多数六轴），若品牌不同（如某些控制器用 XYZ），
   手眼结果会整体偏转，表现为"标定残差小但抓取偏"。`EulerConvention` 已预留切换。
3. **靶标必须固定不动**，且最好覆盖工作区不同位置。

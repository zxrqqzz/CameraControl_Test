# 上下文（插件式，可开关）

> 目标：让 AI 记得以前的对话，同时**不改动前缀**以保持缓存命中；
> 功能整体可以一键关闭、删干净。

## 一、开关：`Mods/context/mod.json`

```json
{
  "enabled": true,
  "maxEstimatedTokens": 1000000,
  "maxEntryChars": 8000,
  "defaultTier": "InjectFull"
}
```

| 情况 | 行为 |
|---|---|
| 文件存在且 `enabled: true` | 启用 |
| `enabled: false` | 禁用（不写文件、不注入） |
| **文件不存在** | **禁用**——删掉即彻底卸载 |
| 文件损坏 | 禁用，并在日志说明"解析失败"，不猜默认值 |

为什么不做 DLL 反射加载：插件一多，反射扫描会拖慢启动；
这里只需要"能关、能删干净"，内置实现 + 文件开关已经够用。

## 二、三个档位

| 档位 | 写入文档 | 作为模型输入 |
|---|---|---|
| `Off` | ✗ | ✗ |
| `ArchiveOnly`（第一档） | ✓ | ✗ |
| `InjectFull`（第二档） | ✓ | ✓ 固定前缀 |

档位**按模型配置分别保存**（换 key 不会串味）。

## 三、目录与文件

```
<数据目录>/context/<配置Id>/
├─ ctx-000001.jsonl          ← 当前上下文（只追加）
├─ ctx-000002.jsonl
├─ archive/ctx-000001.jsonl  ← 满额归档
└─ index.json                ← 档位、活动编号、清单
```

JSONL 每行一条：

```json
{"Role":"user","Text":"有哪些相机","At":"2026-11-13T01:22:33+00:00"}
{"Role":"assistant","Text":"共 2 台","At":"2026-11-13T01:22:41+00:00"}
```

`index.json` 丢失会**从磁盘重建**，不会让上下文凭空消失。

## 四、缓存命中：为什么必须"只追加"

```
第 1 轮请求前：[文档空]                     → 发出
第 1 轮结束后：[in1 out1]                   ← Append
第 2 轮请求前：[in1 out1]                   → 发出（前缀 = 上一轮全文）
第 2 轮结束后：[in1 out1 in2 out2]          ← Append
```

规则只有一条：**已写入的字节永不改写**。全部写入走 `File.AppendAllText`，
绝不"读出来再整体重写"。有一个单测专门做**字节级比对**：
第二轮结束后，文件前 N 个字节必须与第一轮结束时完全一致。

## 五、两个"清空"的区别

| 操作 | 当前内容 | 旧文件 | 新编号 |
|---|---|---|---|
| **开启新对话** | 保留（归档） | 移到 `archive/`，可查 | 是 |
| **清空** | **删除** | 不保留 | 是 |

编号用**单调计数器**，删除后不复用——否则新上下文会拿到旧编号、把归档文件覆盖掉。

## 六、达到上限怎么办

`maxEstimatedTokens`（默认 1M）按字符估算：
中文约 1 字 1 token，其余约 4 字符 1 token。误差 ±20%，够用于阈值判断。

超限时：当前上下文归档 → 新建一份 → 本轮内容写进新的。

## 七、界面

AI 页「上下文」区块：

```
档位：【 完整注入 ▼ 】  [开启新对话] [清空] [管理…]
ctx-000001 · 8 条 · 约 1,234 tok
```

「管理…」打开列表窗口：所有上下文（含归档）、条数、估算占用、创建时间，
可逐条删除或打开所在文件夹。

## 八、隐私

**上下文文档会把你的输入与模型输出以明文写入磁盘。**

这与"采集图像不落盘"是两条不同的策略：
图像是敏感画面，文本是对话历史且必须持久化才能维持缓存前缀。

目前的可控手段：

- 只写 `<数据目录>/context/`，不写系统其它位置
- `.gitignore` 已排除 `/data/`，不会误提交
- 「清空」立即删除当前文件；「管理…」可删任意一份
- 需要更强保护时可后续加 DPAPI 加密（代价：无法用记事本直接查看）

## 九、测试覆盖

| 类别 | 条数 | 关键断言 |
|---|---|---|
| 估算器 | 5 | 中文 1 字 1 token、英文 4 字符 1 token |
| 追加与前缀 | 3 | **字节级前缀不变**、第二轮严格包含第一轮 |
| 轮换 | 2 | 达阈值归档并新建、归档文件真实存在 |
| 两个清空 | 2 | 开启新对话保留旧档；清空删除当前 |
| 档位 | 3 | 只存档不注入；Off 不写；总开关关闭零副作用 |
| 管理 | 3 | 删除生效；索引丢失可重建；超长截断 |
| 开关文件 | 6 | 缺失/关闭/损坏 → 禁用；非法值回落默认 |
| Agent 接入 | 4 | 前缀注入系统消息；完成后记录问答；未配置不读写；读取失败不影响任务 |
